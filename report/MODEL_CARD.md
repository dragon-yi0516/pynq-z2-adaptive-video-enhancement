# Model Card：3-8-3 Q8.8 场景分类 MLP

## 1. 模型概述

| 项 | 内容 |
|---|---|
| 名称 | `mlp_engine`（3-8-3，Q8.8） |
| 类型 | 全连接 MLP，定点 int16 权重/int32 累加 |
| 输入 | 3 个整数特征：`f_luma / f_luma2 / f_grad` |
| 输出 | 3 类：0 暗光、1 逆光、2 常规 |
| 部署 | Vitis HLS，PL 侧，`II=1`、`Depth=7` |
| 版本 | 与 stage13 `VERSION=0x0001020D` 配套 |

## 2. 用途

**Intended use**：为自适应 ISP 选择处理模式（暗光增益/逆光补偿/常规锐化），
面向窗边逆光、暗角、正常光频繁切换的边缘视觉场景。

**Not intended use**：安全关键、医疗、自动驾驶决策；
不能单独用于“场景理解/目标检测”，它只输出三种照明/对比度模式。

## 3. 输入特征

| 特征 | 来源 | 物理含义 |
|---|---|---|
| `f_luma` | `SUM(Y) >> 20` | 平均亮度 |
| `f_luma2` | `SUM(Y²) >> 28` | 亮度平方/对比度 |
| `f_grad` | `SUM(|ΔY|) >> 16` | 水平梯度/细节 |

四象限 `TL/TR/BL/BR` **不进入 MLP**，由 PS 侧空间规则使用。

## 4. 训练数据

| 项 | 内容 |
|---|---|
| 样本 | 540 帧，3 轮 × 60 帧/类 |
| 类别 | 暗光/逆光/常规，各 180 帧 |
| 采集 | 密闭演示盒 + 可控光源 + 手动曝光 736 行 / 增益 0x20 |
| 划分 | 3 折 leave-one-round-out |
| 隐私 | 只保存 3 个统计特征，不保存图像/人脸 |

## 5. 指标

| 指标 | 结果 |
|---|---|
| 3 折留一 MLP macro-F1 | 1.000 ± 0.000 |
| 固定亮度阈值 macro-F1 | 0.942 ± 0.041 |
| 量化前后一致率 | 1.0000 |
| HLS CSim | 124 条，`fail=0` |
| 实时闭环 | 四场景 0/1/2/1，29.7 fps |

## 6. 限制

* 三分类，不是通用场景理解；
* 训练数据是盒子标定，真实房间泛化需补测；
* 三类仍主要由亮度分开（luma-only 98.5%），
  空间信息由四象限规则补足，不在 MLP 内；
* 四象限只有 4 块，不能定位小面积高光；
* 720p30，不是 60 fps；
* 模型容量小（3-8-3），但可解释、资源低。

## 7. 失败模式

| 输入 | 预期行为 |
|---|---|
| 遮镜头/全黑 | 门限拒绝或保持，不强行切 |
| 均匀白墙 | `u` 低，信任 MLP |
| 窗边逆光 | `u` 高，空间规则改判 mode 1 |
| 快速切换 | 防抖 + min_hold，避免振荡 |
| 色偏/过曝 | 可能误判，报告如实写 |
