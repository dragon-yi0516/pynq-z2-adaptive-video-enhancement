# 拍照与演示视频拍摄指南

## 1. 开机前检查

- 确认板上 overlay 为 stage13，`VERSION = 0x0001020D`；
- 只保留一个正在运行的 Jupyter kernel；
- 确认 HDMI 已经出图，而不是只启动了采集通道；
- 运行 `python3 tools/check_weight_sync.py`，确认权重、HLS 和 bitstream 对应；
- 演示全程使用同一档手动曝光，不要在暗光、逆光和正常光之间重新自动曝光；
- 分屏模式使用 `13_verify_split.ipynb`，全屏 A/B 对比使用 `tools/ab_toggle.ipynb`。

### 分屏照片的取景要求

stage13 的分屏方式是：左半屏显示原始画面的前 640 列，右半屏显示同一段列经过处理后的结果。拍摄时把主体完整放在摄像头画面的左半边。这样显示器左、右两边会显示同一主体，方便直接比较。

不要把主体放在摄像头画面中央或右半边，否则分屏中会只剩一部分或看起来两侧内容不相同。

### 照片质量

- 使用后置主摄，关闭美颜、HDR 和人像模式；
- 使用三脚架或把手机固定，避免拍屏幕时手抖；
- 手动锁定曝光、对焦和白平衡，建议 5000～5600 K；
- 屏幕亮度先调到约 70%，避免房间灯光在屏幕上形成大面积反光；
- 拍屏幕时与显示器保持轻微角度，减少摩尔纹；
- 每张至少拍 3 次，再选最清楚的一张；
- 桌面上只保留作品和必要的供电、KVM、鼠标，移走水杯和个人证件。

## 3. 主视频：60 秒版本

建议横屏 16:9，1080p 30 fps 或 60 fps。先拍完整流程，再在剪辑里压到 60 秒。

| 时间 | 画面 | 画面内文字/口播重点 |
|---|---|---|
| 0～5 s | 整机正面全景，HDMI 正在出图 | “这是我在 PYNQ-Z2 上做的 OV5640 自适应视频增强系统” |
| 5～12 s | 摄像头对着窗边逆光场景，屏幕显示分屏 | “普通全局曝光很难同时照顾主体和亮窗” |
| 12～20 s | 暗光场景，先显示直通，再切到处理后 | “暗光模式下自动提高亮度，同时由 PARAM 控制强度” |
| 20～32 s | 窗边逆光场景，使用分屏或 A/B 切换 | “左半是原始画面，右半是处理结果；主体更亮，亮区没有继续被推高” |
| 32～40 s | 带文字或纹理的物体，切到锐化模式 | “正常光场景使用轻量增强，纹理和文字细节更明显” |
| 40～48 s | 笔记本或屏幕上的 Jupyter 日志与 HDMI 同框 | “PL 负责统计，PS 负责场景判断；模式在帧边界切换，画面不撕裂” |
| 48～55 s | 快速展示版本、hard pair 和 soak 结果 | `VERSION=0x0001020D`；hard pair 1.000；1 小时 107,137 帧 |
| 55～60 s | 回到整机，显示仓库地址 | “完整源码、数据和报告已开源在 GitHub” |

## 4. 短版本：30 秒

| 时间 | 内容 |
|---|---|
| 0～4 s | 整机全景 + 项目名 |
| 4～10 s | 暗光场景，直通/处理前后对比 |
| 10～18 s | 逆光分屏，突出主体提亮和高光保持 |
| 18～24 s | 正常光锐化，拍摄文字或织物纹理 |
| 24～30 s | 版本、关键指标和 GitHub 地址 |

短版本不放完整架构图，也不逐项解释寄存器。重点让人一眼看到输入场景、处理效果和作品本体。

## 5. 拍摄方法

### 方案 A：手机直接拍屏幕

- 手机固定在显示器正前方，画面中保留一部分板卡和摄像头；
- 使用 1080p 60 fps 或 4K 30 fps；
- 手动对焦到屏幕文字上；
- 曝光以屏幕不过曝为准，避免自动曝光随画面变化忽明忽暗；
- 先录 3 秒静止画面再开始切换，方便后期剪掉开头。

### 方案 B：手机拍现场 + HDMI 采集卡录屏

如果手上有 HDMI 采集卡，效果更好：

1. 用采集卡录下干净的 HDMI 输出；
2. 用手机拍板卡、摄像头、接线和操作过程；
3. 后期把现场画面放在主画面，把 HDMI 录屏放在右上角或全屏切换；
4. 切换前后保留相同时间长度，不要只放处理后画面。

## 6. 录制前的场景与操作

### 暗光

- 保持摄像头曝光和增益固定；
- 让画面里同时有暗部和一个不太亮的物体；
- 先显示直通，再切到自适应，停留至少 3 秒。

### 逆光

- 让窗户或灯在画面内，但不要让整个画面都过曝；
- 把主体放在画面中部，确认主体轮廓可见；
- 分屏拍摄时，把主体完整放在摄像头画面左半边。

### 正常光

- 拍带文字、棋盘格、包装盒或织物纹理的物体；
- 锐化模式的差异最好用高频纹理展示；
- 不要用纯白墙证明锐化效果。

### 连续自适应

使用 `tools/ab_toggle.ipynb` 做 2 秒一次的直通/处理切换：

1. 先录直通画面；
2. 再录自适应画面；
3. 后期只保留变化清楚的片段；
4. 不要在切换时移动摄像头或改变房间灯光。

## 7. 配音和剪辑

- 配音单独录，使用手机靠近嘴部，环境保持安静；
- 语速控制在每秒 3～4 个汉字，60 秒版本约 180～220 字；
- 背景音乐音量压低到人声的 20% 以下；
- 关键数字用字幕同步显示，不靠观众听一遍记住；
- 每个镜头保留前后 1～2 秒余量，方便剪辑；
- 最后导出 1080p MP4，H.264，码率 8～12 Mbps。

## 8. 发布前检查

- 照片能看清板卡型号、摄像头接线和 HDMI 画面；
- 照片里没有个人信息、聊天窗口或无关文件；
- 视频能同时看到真实设备和显示器效果；
- 版本画面包含 `VERSION = 0x0001020D`；
- 演示过程中没有黑屏、花屏、Traceback 或 Allocate failed；
- 旁白和画面中的场景、模式、数字一致；
- GitHub 地址可访问，仓库和 Release 页面能正常打开。
