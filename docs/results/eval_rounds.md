# 按采集轮次留出：MLP vs 固定亮度阈值

数据：`data/features.csv`，540 帧，每类 180 帧，3 轮 × 60 帧。
划分：leave-one-round-out（训练 2 轮、测试 1 轮，3 折）。
模型：3-8-3 Q8.8 MLP（和板上 `mlp_weights.h` 同一套特征约定）。
基线：只用 `f_luma` 的两级阈值（训练折类均值中点）。

复现：

```bash
python3 tools/eval_rounds.py
```

## 怎么解读

* 这条结果比随机 80/20 的 1.0000 更有说服力：测试轮次在训练时完全没见过。
* MLP 的优势主要来自“轮次间光照漂移”下的边界稳定性；固定亮度阈值在两折里
  把一部分逆光/常规判错，macro-F1 掉到 0.91 左右。
* 但这仍然**不能**证明系统不是亮度分类器：数据的三类中心
  `9.7 / 66.4 / 96.5` 本来就按亮度排开。下一步必须做
  `hard_pairs_template.md` 里的同亮度对比。

## 报告里建议的写法

> 按采集轮次留出（3 折），3 特征 Q8.8 MLP 的 macro-F1 为 1.000，
> 固定亮度两级阈值为 0.942 ± 0.041。说明 MLP 在未见轮次上对光照漂移更稳；
> 但由于三类仍主要由亮度分开，我们进一步用四象限统计做同亮度 hard pair 验证
> （见 hard pair 表）。
